# 接入、刷新与管理数据

状态：完整数据库管理流程为产品目标 / 待实现。当前 alpha 由可信操作者执行脚本，参数见[M1](../design/m1-running.md)、[M2](../design/m2-running.md)；尚无正式建库、通用上传或业务批量写 API。

## 选择接入方式

| 方式 | 权威与责任 | 当前状态 |
| --- | --- | --- |
| 外部湖登记/同步 | 上游事实权威，固定源版本读取或物化 | 有界 Iceberg v2 snapshot 与显式 append 历史子集 |
| 托管数据集 | 数据库通过受控入口提交和管理版本 | 可信单机、固定 schema append 脚本；产品 API 待实现 |
| 外部特征/媒体 | 记录输出来源和输入版本绑定 | 有界向量/媒体引用；完整资产/片段合同待实现 |

不要改内部 PG 行或复制索引目录导入业务数据。先核对[格式矩阵](../compatibility/lake-formats.md)的版本、方向与特性；Parquet 可读不证明湖格式删除/schema 可用。

## 一次接入的目标合同

管理入口应支持选择 namespace/dataset，声明 schema、逻辑键、源版本/对象身份、媒体/特征绑定、所需索引、保留与预算，并返回持久 job/operation。具体公开字段/API 尚待设计。

报告应区分接收、校验、事实提交、构建和发布，给出输入/接受/拒绝计数及原因。重复键、坏类型、缺媒体和错模型按约定失败；未来若支持隔离坏行，必须显式选择并报告，不能默认丢行后称全量成功。

## 当前 alpha 操作路径

1. 建立控制 PG、受保护 root、固定源 metadata/snapshot 和特征摘要；按 M1 准备 target。示例的占位 URI/摘要不是可直接运行的自有数据。
2. snapshot 构建后保存 run/operation，通过 progress 核对 discovered/applied/indexed/published。
3. ready 后以当前 expected epoch 发布；冲突先核对，不能无条件覆盖。
4. 授权后用 describe/search 与固定视图导出核对内容和版本。M0 SQL 启动清单不会自动跟随此指针。

这仍是工程操作。稳定管理 CLI/API、schema 管理和完整自有数据教程是产品交付缺口。

## 刷新与删除

Snapshot 固定目标版本重建；显式增量仅接受已验证 append-only 历史子集。当前索引仍全量重建，源文件增量不等于索引增量。

| 事件 | 处理合同 |
| --- | --- |
| 合法 append | 核对父版本/旧文件/稳定键；新视图发布前旧视图可用 |
| 更新、删除、rewrite、schema/partition 演进 | 当前白名单外拒绝，不能当追加或忽略删除 |
| 历史丢失或换分支 | 停增量；只有 reader 支持目标语义才可按显式策略重建 |
| 超时或响应丢失 | 用原 job/operation 和目标对账，不换 ID 盲目重复写 |
| 索引失败 | 不发布半成品；不把已确认事实提交说成已撤销 |

Continuous、批式 UPDATE/DELETE/MERGE、通用 schema 演进均待实现。旧版本删除还需核对源所有权、历史读取、pin 与保留责任；没有已实现的通用强制擦除 API。

## 权限、预算和恢复

接入者需要源读取和目标写入/发布权限；查询者不应获得控制 PG DSN 或对象存储管理凭据。当前粒度见[安全](security.md)。

接入前检查行数、文件数、维度、run 容量和资源预算。超限应解释并停止；提高常量不能沿用旧证据。失败保留 source/operation/run、日志与配置摘要，按[运维](operations.md)对账。代码 Git 回滚不撤销数据提交。

## 文档替换、下架与标签修订（目标，待实现）

首个图文样板的真实试用须通过正式入口完成这些操作。最小方案可提交受支持输入的完整snapshot，在新revision重建必要索引并原子发布；保持稳定ID/新记录版本和旧合法view。未覆盖的源删除/schema演进仍拒绝，不把变化当作append；最小认证路径由权威源生成完整冻结版本，再通过正式入口重新登记/构建/发布；源writer仍限定append，托管原位覆盖需要后续独立合同。这不是新增SQL DML或源湖写回支持。

普通下架从新视图生效，历史训练引用按保留政策继续存在；撤权须阻断旧view/缓存/媒体的后续受控访问；强制擦除需独立追踪全部派生副本/备份，不能因发布新视图就报告物理删除完成。未知提交先对账，失败保留旧合法视图，具体API及恢复命令在实现前冻结。
