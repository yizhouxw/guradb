# GuraDB 用户手册

GuraDB 是面向 AI 训练、推理与应用的分布式多模态数据库项目。产品目标是统一管理结构化记录、文本、图像、音频、视频、向量和关系，让用户在同一数据版本与权限下完成分析、检索和训练数据准备。

**当前版本仍是受控环境下的有界 alpha，没有生产发行承诺。** 本手册提供产品概念与目标合同、当前可执行操作，各页明确区分。目标章节不是已经支持的 API。正式版本手册尚未完成，缺口见[手册建设与完成标准](manual-plan.md)。

2026-10-20的[概要设计](../design/outline-design.md)细化接入、检索、训练、生命周期和治理部署目标及实施边界；本次仅修订设计文档，没有新增可执行命令、云适配或安全/合规能力。使用当前版本仍按本手册白名单操作。

首个产品样板（待实现）聚焦企业图文知识库：从正式入口接入资料，在共同版本与权限下查询并取得原始证据，再从同一语料准备 embedding/reranker 的训练与评估样本并实际读取。先证明共同视图查询，再贯通接入/更新和训练；完整多机与生产另行验收。语言、模型和业务真值须先冻结，当前 ASCII 分词/256维限制仍按[能力白名单](features.md)执行。

## 阅读约定

- **产品目标 / 待实现**：数据库应交付的语义和流程，不能直接作为当前功能使用。
- **当前有界实现**：已有源码、版本化契约与明确限制；具体部署仍需验证。
- **本轮实测**：必须标注命令、版本/配置和报告。旧版本通过不替代当前证据。

初次体验使用安装页的合成数据；接入真实数据前核对源格式、对象保留和授权。外部生成 embedding、OCR/ASR 结果与数据库自行处理媒体是不同能力。
