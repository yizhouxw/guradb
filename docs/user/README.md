# GuraDB 用户手册

GuraDB 面向 AI 数据准备、检索与训练读取。当前是供可信操作者在受控环境评估的**有界 alpha**，尚无生产发布承诺。本手册描述当前源码的使用合同；某个部署是否通过，须核对相同 commit 和工作区指纹的验证报告。初始化验证范围见[验证记录](validation.md)。

| 要完成的事 | 阅读入口 |
| --- | --- |
| 判断能否满足业务需要 | [产品功能与支持范围](features.md) |
| 理解组件、数据流与一致性 | [技术架构](architecture.md) |
| 构建并运行第一个查询 | [安装部署](installation.md) |
| 接入 SQL、检索、Graph 与训练导出 | [使用指南](usage.md) |
| 配置权限、发布、保留与恢复 | [运维管理](operations.md) |
| 贡献新功能、修复与验证 | [开发指南](development.md) |
| 定位连接、查询、发布与数据问题 | [诊断指南](diagnostics.md) |
| 检查文档验证到什么程度 | [验证与场景映射](validation.md) |

建议首次评估先读功能边界，再运行安装页的本地合成数据示例；接入自己的湖表前阅读权限、固定视图和保留规则。研发设计、调研与 ADR 另见[工程文档索引](../README.md)。

本手册使用三个状态：**当前有界实现**说明源码中的入口及限制，**本次已验证**必须附当前实际命令/报告，**规划**表示尚不能依赖。历史组件通过记录不代表本次部署或完整产品通过。源码能力合同见[能力清单](../../api/capabilities/v1.json)，它是离线文件，并非在线全局能力协商 API。
