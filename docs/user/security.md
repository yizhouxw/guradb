# 身份、权限与数据访问

状态：数据集级有界授权已实现；完整角色体系、TLS/OIDC、行列策略、生产审计与密钥轮换尚未交付。当前只在可信受控环境评估。

## 需要保护哪些入口

数据库权限不仅约束 SQL 行。检索候选和分数、关系路径、作业状态、导出文件、原始媒体、缓存及历史视图都可能泄露信息。产品目标是所有入口使用同一 principal、dataset 和授权上下文。

当前 SQL 服务与检索服务的授权分别配置，不能互相推导。这是待收敛缺口；一个 token 在一个入口有效，不说明它可访问另一个入口。

| 当前入口 | 身份与配置 | 使用注意 |
| --- | --- | --- |
| SQL HTTP / 可选 PG 端口 | M0 auth_file：token SHA-256、tenant/principal、dataset allowlist | 原 token 只由客户端持有；PG user 对应 principal，password 为 token |
| 检索/训练 HTTP / CLI / MCP | 内部目录 grant 与客户端 token | 目录 DSN 只给操作者；下载也要复查授权 |
| 本机 HTTP worker | 共享任务密钥与 owner/generation | 不是最终用户 API；密钥不进入任务正文/日志 |

正式产品还需明确管理员、接入者、发布者、查询者、训练消费者和审计者的操作矩阵；这些角色名是待设计职责，不是现有角色 API。

## 当前授权操作原则

M0 更新 auth_file 应在同目录写完整临时文件、校验并原子 rename，设置受保护文件权限；不要 truncate 正在使用的文件。配置无效时拒绝访问。M1 授权按[运行说明](../design/m1-running.md)维护，不能直接改索引绕过。

凭据经受保护文件/环境注入，不能写进仓库、命令示例、任务报告或 URL。示例公开 token 只用于合成数据本机体验，不能用于共享部署。具体配置见[运维](operations.md)。

## 撤权与历史版本

撤权必须影响后续受控请求、执行与结果/对象访问，不能等待重建索引；历史 pin 不赋予永久访问权。已下载的字节无法由数据库追回，上游签名 URL 也受独立权限和有效期约束。需要严格撤权时应采用受控代理访问；当前不承诺完整媒体网关。

数据删除、保留期结束和安全强制擦除不同。普通删除可以保留历史视图；擦除若要求所有副本/备份同步处置，需要独立政策与证据，当前没有该产品保证。

## 部署和验证

当前没有内建生产 TLS/OIDC，PG 端口仅 loopback；不能把示例公网暴露。未来远程部署需验证传输保护、外部身份、租户隔离、对象授权、日志脱敏和恢复后撤权补偿。

验证至少包括错误 token、越权 dataset、撤权后的旧句柄/下载、图路径越权、无效授权文件、缓存命中与权限失效竞争。通过单一 API 的认证正例不证明整个系统的安全边界。
