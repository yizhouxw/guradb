# 多模态混合检索与证据

状态：完整 SQL/检索/关系联合计划与资产片段证据模型待实现；当前 HTTP/CLI 有界检索见下文。

## 从问题设计查询

“查找某型号设备的过热故障，返回手册原文和示意图”：结构化条件限定型号，全文找精确术语，向量召回语义片段，关系扩展相关部件/案例，融合后返回证据。产品目标是在同一授权视图中完成。

当前文本/向量/RRF 通过 HTTP/CLI，Graph 是独立一跳作业，SQL 是另一服务路径。应用拼接结果不代表数据库已有联合查询。

| 方式 | 用途 | 要观察的边界 |
| --- | --- | --- |
| 结构化过滤 | 类型、标签和业务键 | NULL、过滤位置、权限与版本 |
| BM25 全文 | 型号、术语和关键词 | 分词语言、全局统计、分数版本 |
| 精确向量 | 完整距离对照 | 空间/维数、距离方向、扫描预算 |
| ANN | 有界候选加速 | recall、probe、选择性、回退/精排 |
| 融合 / 重排 | 合并多路召回 | 候选窗口、RRF/权重、确定性同分 |
| Graph | 扩展关联证据 | 端点版本、方向、跳数/扇出、路径/截断 |

ANN top-k 不等于精确全库 top-k。BM25 与向量分数不同单位；RRF 不自动产生概率或跨查询可比置信度。

## 当前可执行请求

先完成[接入](ingestion.md)、发布与授权，设置实际 `DATASET` 与 `GURADB_TOKEN`。模型/向量要替换为真实值：

```sh
.venv/bin/python clients/cli/m1.py describe "$DATASET"
.venv/bin/python clients/cli/m1.py search --dataset "$DATASET" \
  --query '{"text":"overheating","vector":[0,1],"model":"demo-v1","candidate_limit":100,"top_k":10}'
```

默认本机地址；需要时在子命令前传 `--url`。核对 describe 的 schema/model/read_context；未构建 ANN 不能默认使用。当前平方 L2、ASCII 小写分词、候选与规模限制见[能力页](features.md)；不支持的中文分析器不能用中文例子冒充通过。

响应按[HTTP 契约](../../api/http/m1-openapi.json)解释，不根据下面目标合同猜已有字段。

## 结果的目标合同

结果应关联命中 ID/version、实际 view/revision、字段/片段、资产版本与坐标、各路排名/融合、近似/截断说明及受控媒体访问。稳定字段/API 尚待设计。

新发布可能改变结果；固定视图/配置下的差异须可解释。模型、分词器和索引变化须记录版本。分页不能换版本重新召回，Graph 端点不能到另一 latest 解析。

## 安全、预算与质量

授权覆盖候选、融合、关系路径、回表和原始对象；仅应用最终过滤不足以构成权限合同。旧索引/缓存/视图不能绕过撤权。

ANN 评估同时记录精确 recall、相关性、过滤选择性、冷/热/部分缓存、构建/存储成本、请求/字节和总内存。少候选、漏读或换暖缓存的速度不能称同质量提升。

模型不符、缺片、对象丢失或必需索引缺失要诊断失败；预算超限与允许截断分别说明，不能静默缩小范围。当前 Graph 仅一跳，参数见[M2 操作](../design/m2-running.md)。完整调优与生产证据仍缺，见[生产准备](production.md)。
