# 设计多模态数据集

状态：产品目标合同 / 待实现。当前没有完整资源创建、约束与跨表关联 API；已有白名单见[支持范围](features.md)。

## 先确定样本单位

一条数据可能是文档、图像、视频片段或带多种传感器数据的观测。先确定检索、授权与训练消费单位，再定义稳定逻辑 ID。文件名、行号和分片位置不适合作长期身份。

以下是检修资料的逻辑设计，不是当前建表语法：

| 对象 | 示例字段 | 含义 |
| --- | --- | --- |
| 资产 | asset_id/version、media_type、object_identity、设备型号 | 原始资料的确定版本 |
| 片段 | segment_id/version、parent_asset_version、coordinate | 页、段落、区域或时间片段 |
| 特征 | input_id/version、model_id/version、space、dimension、output_ref | 某个输入的处理输出 |
| 标签 | target_id/version、label_schema、value、来源 | 人工或模型标注 |
| 关系 | edge_id/version、typed_source/target、type、evidence | 带类型端点的有向关系 |
| 训练样本 | sample_id/version、成员角色与对象版本、group_id、recipe_version | 可组合多个记录/片段/标签的消费单位，不复用物理行号 |

资产版本可有多个片段，片段版本可有多个模型特征。父资产更新不证明旧坐标仍正确；新特征不能覆盖旧训练集依赖的输出。关系端点要说明是资产还是片段。

## 不同模态的定位

| 模态 | 原始身份 | 片段定位要素 | 常见错误 |
| --- | --- | --- | --- |
| 文本 / PDF | 字节版本、编码/文档类型 | 页码基准、文本区间、提取器版本 | 换提取器沿用旧偏移 |
| 图像 | 图片版本、宽高、方向 | 像素/归一化坐标、区域与变换来源 | 旋转后区域映射错误 |
| 音频 | 音频版本、时基/声道 | 起止时间、单位、边界、转录来源 | 把采样序号当毫秒 |
| 视频 | 视频版本、时基 | 时间区间、帧定位、音轨映射 | 跨转码只按帧号匹配 |

公开坐标 schema 尚待冻结。首个产品闭环优先验证文本与图像；音频/视频不能因已有 URI 就标完整支持。外部片段接入、内建解码、OCR/ASR、抽帧和 embedding 分别验收。

## 特征与模型升级

embedding 记录模型身份/版本、空间、维数、距离和归一化约定。维度相同不证明空间相同；跨模态比较须声明共享空间或融合策略。

模型升级先生成新特征/索引，质量验证后发布新视图；旧消费者结束前保留旧输出。不可重复调用的模型输出要持久保留，不能以索引可重建代替保存特征。

训练样本应分别标记 query、positive、negative、image、label 等成员角色及精确版本；角色按首批样本类型白名单验收。一个记录可参加多个样本，一个样本也可引用多个记录。文档族、实体或近重复组在分块/增强前确定划分，后续片段与副本继承组归属；跨版本沿用持久组映射，规则变化产生新版本。详见[训练合同](../product/training-contract.md)，当前 alpha 尚无这些对象/API。

## 身份、schema 与变更

稳定键须声明类型、唯一性和 NULL/重复策略。无键源可以有固定快照读取合同，不能自动获得逐行增量。列重命名/删除、类型变化、模型空间和端点变化都是兼容事件。

托管数据集与外部同步分别声明写入权威。外部湖同步表示不能被应用独立写入；同时维护两套主表会失去共同真值。

## 建模验收

- 检索定位原始版本、坐标和证据，不只返回向量行号。
- 样本明确资产/片段、标签与特征；缺模态的拒绝/过滤/缺失策略显式。
- 关系有有效版本、悬空边与删除策略，不隐式关联 latest。
- 保留和授权覆盖全部依赖与媒体下载。
- 负例包括重复键、缺父版本、错坐标、错模型空间和失效对象。
