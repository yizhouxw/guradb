# M3 本地三 worker 运行时切片

状态：实现中，验收仅同一主机真实子进程，不等于跨机器分布式或完整 M3。

服务以 `serve --workers 3` 开启；每项任务把固定 bundle 中的记录按稳定逻辑键排序后轮转分成3片。
子进程通过有界、带摘要的任务文件接收精确视图和授权作用域；无监听端口、不下发 PG/token 凭据。
协调器在执行前和发布结果时重验授权；view/job pin 贯穿任务。每片唯一 task ID + 输入摘要，结果必须匹配，缺片、重复片、进程退出或超时导致整项失败。
扫描、精确向量候选和一跳 Graph 分片执行并全局归并，统一候选窗口/同分排序/RRF；新视图使用三份物理BM25 postings及同一全局统计、三个独立Lance ANN索引；全局排序及RRF在协调器归并。旧视图保留共享索引兼容路径。
新Snapshot构建时将完整行（值、向量、媒体、稳定版本）持久分成三个互斥Parquet。worker只读本片，训练转换分片执行，协调器写同一排序Parquet；复杂exchange未实现。
每个非空片必须提供独立PID、实际记录数和该worker峰值RSS证据。每进程RSS门槛512MiB；报告各进程峰值之和，不将其称为同时总峰值。3进程仅本地部署方式；不支持跨机器worker、HA、自动重平衡、spill/通用JOIN。

预算沿用原作业10秒总 deadline/取消，子任务输入合计<=32MiB、输出合计<=32MiB；最多3 worker/请求及2请求并行。
每个worker只接收本片数据，完成后退出；故障杀进程组并收割，禁止自动重试未知外部副作用。
真实测试比较单节点真值、3个独立PID与各片记录数、失败/取消、同视图训练与新发布竞争。
本切片提供本地并行执行证据，不把本机共享文件系统等价为远端对象/网络/HA证据。

新版BM25评分与兼容边界见[ADR 0013](../decisions/0013-local-p0-partitions-and-recovery.md)。剩余读取/产物预算等分给worker并在收集结果时汇总；skew可能保守拒绝。worker `work.budget` 和 `work.vector_index` 区分实际成本与小片精确回退；不把本地文件读取字节称为远端网络物理I/O。
