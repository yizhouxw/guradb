# ADR 0001：产品约束与初始化边界

- 状态：已接受（仅记录用户已明确的产品方向）
- 日期：2026-10-17
- 依据：本项目的初始需求

后续边界补充见 [ADR 0002](0002-object-store-lake-boundary.md)；本记录保留初始化时点，不代表技术选项仍全部未收敛。

## 背景

AI 训练、推理与应用需要共同访问多模态数据，并组合关系、全文、向量及图检索。项目需要支持海量数据和开放数据生态，提供便于 AI Agent 使用的接口。

## 已确定需求

1. 建设分布式多模态一体化数据库。
2. 面向 AI 训练、推理和 AI 应用场景，支持多模态数据存储与检索。
3. 支持 SQL、全文检索、向量检索和 Graph 检索，并考虑组合使用。
4. 兼容主流湖格式，特别是 AI 多模态相关的数据格式；覆盖目标通过格式/版本/能力级别持续细化。
5. PostgreSQL 语法兼容，提供 SQL 与 HTTP 接口，并方便扩展 CLI 和 MCP。

## 初始化处理

本轮为上述方向建立语言中立的模块地图、文档、接口草案、示例和检查入口。技术文档中的建议均保留提案状态。尚无数据库功能实现。

## 尚未决定

实现语言、数据库内核复用方式、物理存储与索引算法、共识和事务协议、具体 PostgreSQL 兼容版本和范围、wire protocol、首批格式版本与写回能力、部署拓扑、许可证。

## 影响

后续技术决策需要说明如何满足这些产品约束，并逐步补齐验证证据。不能将格式覆盖愿景解释成所有格式/版本/功能的即时支持承诺，也不能将 PostgreSQL 语法方向解释为完整 PostgreSQL 行为兼容。
