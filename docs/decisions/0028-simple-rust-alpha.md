# ADR0028：单机 Rust alpha 一次切换

2026-10-29，用户明确采用：可信单用户、单本地固定Parquet、单Rust进程SQL。
本决定替代当前alpha对旧HTTP/PG/Python索引/worker及多租户、通用版本/pin/lease/GC
平台的准入前置；这些能力退出当前支持，不保留双在线实现。对象存储湖与未来
Rust检索方向仍为后续设计；#125原数值失败不改写、此片不接检索消费者。

最小实现：单CLI，原SQL白名单和Arrow/DataFusion受限执行逻辑，源SHA256与不可变
bytes保障本次读取，成功发布前复核源。RAII与进程退出清理；未用平台不造协议。
先实际黑盒验证成功/坏输入/失败可重跑/超时/SIGINT，再删旧生产模块、启动路由、
无用依赖及重复操作说明。Python仅保留测试、准备、客户端或工程的实际用途。

新alpha专属core门禁验证必要Rust fmt/clippy/test、真实CLI和退役清单；
源码/门禁变更失效旧证据，错误/缺证据拒绝。核心通过不等于强化/发布通过。
独立复核、正常hook/PR、精确main检查继续；不恢复远端CI或部署。
历史Git可恢复已退役源码，不要求逐模块兼容迁移，不重写已合入历史。
