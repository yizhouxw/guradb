# 本地 P0 集成独立复核

基点 `0b3af06e1719fa2980a04c3b23b4e33cec0f61a1`，任务 `local-p0-integration`。
本轮使用三个 gpt-6.1-sol / low 子代理并行实施和交叉复核；主代理做集成、真值、预算及兼容检查。
最终提交、提交后报告及 checkpoint 以 task receipt 为准；以下是实现与复核记录，不代替当前指纹门禁。

## 发现及处理

- 增量读取在关闭文件后记录stat，可能将旧字节绑定新身份。独立代理真实复现，改为同fd读前后fstat、路径身份复核，补读取期间改写负例。
- ready阶段按`.parquet`后缀复验漏掉合法无扩展名文件；改用完整旧文件集合。继承的Arrow/物化字节纳入总预算。
- 三worker独立Budget没有汇总。改为预分配剩余额度、父级汇总，真实三进程负例证明各片分别小于总额度但合计超过时仍整体失败。ANN输入文件核验及逻辑字节计数加入预算。
- BM25不使用分片局部统计；独立闭式公式、偏斜词频、过滤、空片与RRF验证。新bundle version 2防止旧reader默默采用不同评分；旧v1保持显式兼容路径。
- 恢复通用字符串替换会改动业务正文。改为结构化字段搬迁，正文恰含旧root的真实负例通过。Avro搬迁保留Iceberg header，再用恢复后的源construct验证；源目录与备份根重合等布局明确拒绝。
- HTTP取消原先等待慢请求完成，独立服务复现4.014秒延迟。改为绝对deadline/watchdog主动关闭socket，滴字节响应及取消回归验证。
- HTTP在header之后才设连接限额，改为accept前准入及解析前超时。修复派生source key越界、业务path/root列误判、128去重记录无TTL回收。
- 服务SIGKILL遗留worker及scratch。增加父亡监督、native后代回收和独占目录重启清理；真实服务杀死+阻塞任务+重启验证，未知任务明确abandoned。
- 索引重建独立复核验证只跳过派生文件、事实副本校验、新run完整复制、旧pin及GC、operation/CAS；独立真实PG/ANN运行通过。

## 局部证据

真实SeaweedFS S3/PG增量额外验证64+16行、旧data GET=0、新data GET=1、真实HEAD、旧源篡改/删除拒绝；外部错误归一化避免泄露响应。真实PG增量、联合恢复、重建、只读状态脱敏，以及三worker原生/HTTP并发均有独立driver。
合同集合曾完整运行59测试通过；最终集合以harness为准。HTTP 60秒focused负载实际62.7秒、44轮、264请求，只有本地短时意义。
首次ANN合同运行出现macOS killpg PermissionError；单独重跑和后续完整合同成功，保留诊断，不能拿一次偶然绿色替代最终全任务证据。
恢复、增量竞态与bundle v2迁移过程失败日志均保留artifacts，未删用例、改阈值或绕过hook。
新增验收命令增加CI总预算（change240/release360分钟），保持各命令/性能阈值，CI预算自测覆盖总和；不是性能门槛放宽。
